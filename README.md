# Консольный калькулятор

## Назначение проекта
Простое консольное приложение на Python, которое выполняет
арифметические операции над двумя числами, введёнными пользователем.

## Какие задачи решает программа
- Считывает два числа и операцию с клавиатуры
- Выполняет сложение, вычитание, умножение, деление,
  целочисленное деление, остаток от деления и возведение в степень
- Обрабатывает некорректный ввод чисел (не число)
- Обрабатывает неизвестную операцию
- Обрабатывает деление на ноль

## Инструкция по запуску
1. Убедитесь, что установлен Python 3
2. Откройте терминал в папке проекта
3. Выполните команду:
   ```
   python calculator.py
   ```

## Как пользоваться программой
1. Введите первое число
2. Введите знак операции: `+`, `-`, `*`, `/`, `//`, `%`, `^`
3. Введите второе число
4. Программа выведет результат

Если введена неизвестная операция — программа попросит ввести
операцию заново. Если введено не число — программа попросит
повторить ввод. При делении на ноль будет выведено сообщение об ошибке.

## Пример работы
```
=== Консольный калькулятор ===
Доступные операции: + - * / // % ^

Введите первое число: 15
Введите операцию: *
Введите второе число: 4
Результат: 60
```

## Новый функционал (Практическая работа №2)

- **calculator.py** — выполнение нескольких операций подряд; обработка
  неправильной операции, деления на ноль, некорректного ввода чисел
  и неверного ответа на вопрос о продолжении.
- **converter.py** — повторные преобразования; добавлены конвертеры
  «Литры → Галлоны» и «Мегабайты → Гигабайты».
- **number_check.py** — анализ нескольких чисел подряд; добавлена
  проверка «является ли число полным квадратом».
- **purchase.py** — добавление нескольких товаров в одну покупку;
  проверка положительной цены и количества, непустого названия;
  вывод общей стоимости, скидки и итога.
